# Experiments

Keep a separate record for each experiment.

For each test, document:

1. Objective
2. Environment and versions
3. Preconditions
4. Exact commands
5. Expected result
6. Actual result
7. Evidence
8. Conclusion
9. Safety and rollback considerations

Do not record an experiment as successful unless its result was observed.
Do not perform a firmware upload without an appropriate test image and a
defined validation and recovery plan.
